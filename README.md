# Voxy Speed Gen Wiki

This is the documentation site for **Voxy Speed Gen**, a Fabric mod that generates LODs for [Voxy](https://modrinth.com/mod/voxy) in the background, so distant terrain shows up without flying around or pregenerating first.

**Read it here: https://nayanct.github.io/vsg-wiki/**

The wiki covers:

- Installing the mod and what you need with it
- The terrain modes (Fast, Balanced, Real Chunks) and tree settings
- Every setting in the settings screen and every command
- Servers, pregeneration, map overlays and shaders
- Troubleshooting and FAQ

## Download

The mod is on Modrinth: https://modrinth.com/mod/voxy-speed-gen

## About this repo

The whole site is a single page, `index.html`, with screenshots in `img/`. It's hosted with GitHub Pages straight from the `main` branch, so there's no build step. Open `index.html` in a browser to view it locally.
